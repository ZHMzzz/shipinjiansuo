# Qwen 自然语言结果自动过滤验证

2026-10-27，现有 Qwen3-VL-Embedding 2B / FP16，40 个视频、129 个片段。不更换模型、不重建索引、不启用重排。

## 方法与默认规则

保存上线前 19 组查询的每视频最高分结果，12 组用于确定规则，7 组用于独立检查。正例来自已有测试素材与内容核对；负例包含完全无关主题和仅部分条件相似的描述。人工抽查候选代表帧，发现视频 7、8 均为室内场景，因此将“户外慢跑”修正为预期无匹配查询。已知正例列表不是全库完整人工相关性标注，不能将下面的通过率解释为精确率。

- 最高分低于 0.52：整条查询返回空结果，避免强制推荐最相似但不相关的视频。
- 否则仅保留分数不低于 `max(0.45, 最高分 - 0.08)` 的候选。
- 先确定候选视频的最佳片段，再过滤，最后截取数量与分页。
- 人物与场景使用原始 `scene_similarity`，不使用融合排名分或人脸分。
- 物体图片、纯人名和无条件浏览不使用这组阈值。

只设 0.52 的单一绝对门槛会丢弃“工人坐在桌前低头书写”的已知正例（0.467），而制作披萨的最高误匹配达到 0.509，因此分开使用查询级最高分门槛和候选级门槛。相对差距过滤解决高分查询仍带出大量低分视频的问题。这些常数仅为当前模型和本地素材的初始默认值，模型或语料明显改变后需重新校验。

## 已知局限

- “有人在户外慢跑”：库中两个慢跑素材都为室内场景，仍保留室内跑步/走路等 5 个误匹配。
- “戴红色安全帽的人骑自行车”：最高分 0.534，仍返回含安全帽或出行场景的 3 个误匹配。
- “工人坐在桌前低头书写”虽保留正确视频 27，前面仍有其他人物场景误匹配。
- 阈值无法逐项验证动作、场景、颜色等复合条件，也不能纠正模型本身的排序。没有为个别查询硬编码规则，没有以固定 Top-K 伪装相关度过滤。

`baseline.json` 保存未过滤分数；`evaluation.json` 为规则回放结果；`evaluate.py` 可离线复算。`calibrate.py` 是上线前采样脚本，已有 baseline 时拒绝覆盖；上线后图库 API 已过滤，不能再将该接口输出当作未过滤基线。
