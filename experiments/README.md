## 按需恢复实验数据

优先在 GitHub 固定提交中按需下载单个文件，不必为了运行主程序恢复全部历史。若需要完整实验目录，下面的命令会下载旧提交历史并将所选目录恢复为本地文件，可能包含大文件：

```sh
git fetch origin f5bc7e04e9203ab06b4def75b7038199215ee6ff
git restore --source=f5bc7e04e9203ab06b4def75b7038199215ee6ff --worktree -- experiments/action-search
```

将最后的路径换成确实需要的实验目录。旧源码、模型版本及原开发库可能与当前环境不同，恢复素材不保证旧脚本可以直接运行；先阅读该实验说明，不要对当前在线库直接回放旧迁移或清理命令。浅克隆只需运行主程序时，不要执行上述历史下载。

`/mvp/actions.html` 是可选的本机历史回放页，只有对应结果和视频文件存在时才能播放。缺少这些数据时会提示返回主检索台，主页面的自然语言、物体图片及人物检索不受影响。

本次采用普通提交移除当前版本文件，没有重写 Git 历史；完整克隆的历史体积不会因此立即下降。首次运行使用 `git clone --depth 1` 或最新源码 ZIP。
