# 当前帧特征提取耗时与优化方向

2026-10-28。结论：**OWLv2 视觉计算是主要开销；其次是重复启动、导入、加载和预热。人脸及数据库写入占比较小。** 本轮只做隔离分析和 SDPA 可行性探针，正式配置没有修改。

## 计时与边界

沿用上一轮媒体40、35.44秒视频的已转码像素。克隆当前44视频库，在独立副本运行正式帧提取入口，保持快速CPU处理器、OWLv2 MPS FP16、InsightFace CoreML、2fps及阈值不变。先运行无插桩对照，再运行嵌套计时；不运行Qwen、重建搜索索引、发布或重新转码。

本轮无插桩31.264秒，插桩31.526秒（相差0.84%）。上轮完整上传中的该阶段为34.511秒，两轮进程驻留和系统状态不同，不能把这次分项硬套成上次34.511秒的精确拆分。模型参数和71帧输入相同，输出均为10653条物体区域、77条人脸向量；两次输出向量及元数据逐项一致。

| 本轮帧提取阶段 | 秒 | 占帧提取时间 |
|---|---:|---:|
| OWLv2：预处理、模型、后处理 | 21.836 | 69.3% |
| 启动/导入/退出、模型加载及预热 | 6.638 | 21.1% |
| InsightFace逐帧处理 | 1.494 | 4.7% |
| 向量/缩略图数据库及FAISS写入 | 0.831 | 2.6% |

| 其他未单独计时工作 | 0.225 | 0.7% |

启动/导入/退出残差4.599秒，模型初始化整体2.039秒；初始化内部人脸工厂0.565秒、OWL工厂1.165秒，其他初始化工作约0.309秒。导入时间包含探针准备，不能声称能原样消除全部6.638秒。

OWL内部视觉骨干20.571秒；含预测头和搬运的forward共21.097秒；CPU快速预处理0.561秒，元数据构造0.047秒，其余0.131秒。子阶段包含关系不能重复相加。

人脸检测71次共0.774秒，识别77次0.624秒，年龄性别77次0.085秒。跳过年龄性别几乎无整体收益，且会改变已有元数据。启动时仍创建后丢弃的两个landmark会话仅约0.065秒，也不是优先项。

向量库10730次逐条插入共0.752秒，FAISS逐条add共0.068秒，保存分片0.005秒，缩略图插入0.007秒。数据迭代计时包含解码和缩略图生成，不把它误称为纯视频解码。

## 优化建议

1. **优先测试入库worker与模型复用。** 当前每个任务新建提取子进程，重复Python导入、会话/权重加载和预热。复用独立入库进程可保留当前模型、像素和阈值，避免改变查询端配置。可优化预算约6.6秒/样本，实际收益必须测试；首次任务仍需初始化。代价是额外常驻内存，需限定并发、设置空闲回收及进程失败后重建机制。不要把查询模型和入库模型混用。
2. **大幅降低OWL计算需更实质的计算量减少。** 例如物体抽帧由2fps试到1fps，保留人脸采样率；对应约71帧减少到约36帧，但短暂物体和快速动作可能漏检，必须验证检索召回。现有帧管线共享采样参数，分模型采样需改调度，不能直接全局改低后宣称人脸不受影响。降低分辨率也需适配位置编码并评估小物体召回；本轮未测量这些方案。
3. **数据库与FAISS批量写入可做，但优先级较低。** 现有仓库已有`create_many`能力、FaissStore.add支持多ID/多向量，可按一帧批量写入；须保证ID与区域元数据及时间一一对应、失败事务回滚。本样本全部写入仅0.83秒，理论上也不能省出数秒以上。
4. **不优先增大OWL批量。** 此前实际batch=2没有稳定收益，且显著增加峰值内存；本轮不把它重新列为已验证加速手段。

## SDPA可行性补测

当前Transformers 4.57.6的OWL注意力仍显式执行矩阵乘法、softmax和矩阵乘法。本轮仅在进程内替换视觉编码器注意力为PyTorch SDPA，复用Q/K/V和输出权重，保持原Q缩放位置；遇到mask、训练或请求attention权重则回到原方法。参考 [PyTorch 2.8 SDPA](https://docs.pytorch.org/docs/2.8/generated/torch.nn.functional.scaled_dot_product_attention.html) 及 [MPS实现](https://github.com/pytorch/pytorch/blob/v2.8.0/aten/src/ATen/native/mps/operations/Attention.mm)。这是本地改写，不是声称HF对本模型已有开关或MPS会使用CUDA FlashAttention。

使用同视频0/5/15/30秒四帧，模型已驻留，实际完整图像特征提取（含预后处理）ABBA两轮：基线均值1.1614秒，SDPA 1.1132秒，约快4.15%。该收益不是完整上传收益。

浮点差异导致四帧共11个patch跨越0.02阈值，保留区域数从`330/207/118/147`变为`328/208/118/149`。对齐patch的最低余弦约0.9323，中位数约0.999994；最大框坐标分量差约0.152。全patch极值包含低分背景，不能直接推断有效检测准确率，但已有数量变化且未完成全库检索回归。**收益有限，暂不建议直接采用。** 如继续，应先验证完整库区域/框/检索排名与内存，再决定是否接入。
