# 全库 2B FP16 与 8B Q8_0 对比

本次覆盖全部 **40 个视频、129 个现有片段、68 条中文查询**。先核实并冻结标注，再顺序运行两模型。每模型编码全部 129 段，并执行 3 轮、共 204 次未缓存查询；质量评分只使用第一轮。

56 条主查询中，2B 首位严格命中 **53/56**，8B Q8 首位严格命中 **55/56**。8B 新增首位命中 2 条，丢失 0 条，净变化 +3.6 个百分点。

**结论：8B 在这批素材上有局部改善，但收益集中，暂不足以支持默认替换 2B。** 新增的两条首位命中 B36/H14 都是同一个“夜间室外黑裙女子”场景的不同说法，不能视为两个独立场景的提升。8B 更好地区分了室外活动现场与黑色背景棚拍；其代价是全库编码约慢 70%、Metal 分配峰值约增加 82%。本轮热查询中位数接近。现有模型与索引继续保留。

现有模型权重、索引、配置、40 个源视频和活动项目指针保持不变；没有切换在线模型。工作区同期有一处 `scripts/action_search.py` 的结果去重改动，非本实验写入，详见末尾审计。

## 速度

| 指标 | 2B FP16 | 8B Q8_0 |
| --- | ---: | ---: |
| 观测到的模型加载时间 | 57.457 秒 | 14.296 秒 |
| 全 129 段编码耗时之和 | 524.428 秒 | 889.307 秒 |
| 全 129 段循环墙钟时间 | 545.491 秒 | 957.985 秒 |
| 片段编码中位数，去除首段 | 3.762 秒 | 6.615 秒 |
| 片段编码 P95，去除首段 | 6.897 秒 | 9.192 秒 |
| 热查询中位数，后两轮共 136 次 | 0.190 秒 | 0.200 秒 |
| 热查询 P95，后两轮共 136 次 | 0.438 秒 | 0.254 秒 |
| FAISS 查询中位数 | 0.099 毫秒 | 0.155 毫秒 |

本轮热查询中位数之比（8B/2B）为 **1.05×**，全库编码耗时之比为 **1.70×**。

片段编码时间包括画面预处理和模型推理，8B 还包括本机进程间传输；不含原视频解码。解码及压缩帧准备在计时前完成。循环墙钟时间另含读取压缩帧和实验日志写入；两者都不是完整上传入库耗时。热查询包含重新编码文字与 FAISS 检索，没有应用层查询缓存，不含页面、网络、结果元数据回查。加载时间受文件缓存和运行时差异影响，不能解释为受控冷启动成绩。

后两轮查询中位数分别为：2B 约 198/160ms，8B 约 207/194ms。8B 本轮 P95 较低，但机器有交换内存和同期后台工作，不能据此宣称其尾延迟稳定优于 2B。与上一轮小样本的速度比不同，尤其 2B 本轮时延更高；不要把任何一轮的倍数当成固定性能关系。

## 内存

| 阶段与指标 | 2B FP16 | 8B Q8_0 |
| --- | ---: | ---: |
| 视频编码：Metal 分配峰值 | 5.15 GiB | 9.36 GiB |
| 视频编码：进程树 RSS 峰值 | 0.58 GiB | 2.84 GiB |
| 视频编码：macOS physical footprint 峰值 | 6.29 GiB | 2.13 GiB |
| 查询：Metal 分配峰值 | 5.13 GiB | 9.36 GiB |
| 查询：进程树 RSS 峰值 | 0.25 GiB | 2.52 GiB |
| 查询：macOS physical footprint 峰值 | 6.22 GiB | 2.02 GiB |

Metal 指标：2B 为 PyTorch MPS driver 分配，8B 为 Metal currentAllocatedSize，50ms 采样；RSS/physical footprint 为工作进程及子进程，100ms 采样。查询阶段保留刚完成视频编码后的运行时缓存。不同指标不相加。GGUF 权重使用 mmap，physical footprint 的低值不能解释为 8B 总体更省内存。

系统在测试前已有明显交换内存占用：2B 开始 17.00 GiB、8B 开始 19.62 GiB；测试中最低系统可用内存分别为 3.24 GiB、2.54 GiB。这是有其他应用运行的共享机器，不是受控空载环境，速度比值仅代表本轮观测。

## 标注、输入和审计

- 标注由 Codex 单人视觉核查完成，非两名独立人工标注员复核。全库使用带时间的 1fps 序列图，短动作补看 4fps 序列和局部细节，关键窗口检查真实 16 帧输入；未逐帧浏览所有原视频。标注细节见 [ANNOTATIONS.md](ANNOTATIONS.md)。
- 68 条中有 6 条运行前修正：门岗桌面假设、雨天过街假设，以及背景骑行不确定的无答案题。原文、固定文本及理由均保留在 `query-amendments.json`。B16 的正例从装修环境纠正为真正仓库画面。
- 2B 直接调用现有生产提取器（FP16/MPS），8B 使用上一轮固定的 Q8_0 主干和视觉组件（llama.cpp/Metal）。比较对象是两种部署组合，不可单独归因参数量或量化；没有 8B FP16 对照。
- 全部 129 段使用生产采样公式、同一组 16 帧、8 秒窗口/4 秒步长、同一图像预算和系统模板。129 段的文本 token、时间标记、EOS、视觉 token 数及总 token 数全部一致；RGB uint8 转换最大误差为 0。
- 2B 实验向量与现有索引逐行余弦最低 0.99999988，中位数 1.00000000。2B 三轮完整排名一致：True；8B：True。
- 审计检查 57 个权重、索引、配置及相关代码文件，并再次核对 40 个源视频哈希。模型/索引/配置/源视频和活动指针未变。唯一记录的受检代码变化是工作区并发修改的 `scripts/action_search.py`（增加按视频分组），其差异不涉及采样与编码，保存在 `concurrent-action-search-change.diff`。本实验没有修改任何生产代码。
- 查询来自本库可见内容，且部分视频含字幕和演示检测框，模型可能利用文字；这些结果不能直接推广为无字幕、陌生场景或真实监控泛化能力。
