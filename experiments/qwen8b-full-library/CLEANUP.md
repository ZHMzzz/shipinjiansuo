# 保留 2B 与实验归档清理记录

用户决定继续使用现有 Qwen3-VL-Embedding-2B FP16，暂不切换 8B；保留两轮测试报告及实验结果，删除不再需要的 8B 大文件。

已清理约 **9.77 GiB（10.49 GB）** 的文件占用。清理前后系统可用空间分别为约 **17.02 GiB、26.78 GiB**；系统可用空间会随其他进程和文件系统变化。两轮实验目录目前合计约 41 MiB，另保留设计阶段的小型预览图。

- `../qwen8b-int8/models/`：8B Q8_0 主干和视觉组件权重，以及目录内下载缓存。
- `../qwen8b-int8/runtime/`：本实验专用 llama.cpp 库、下载压缩包、头文件和编译产物。
- `../qwen8b-int8/frames/`、本目录 `frames/`：可由原视频重新生成的采样帧、无损传输文件与对齐 RGB 缓存。
- 本目录 `aligned-encoder`：8B 专用可执行文件。
- 两实验目录的 `__pycache__/`。

删除限定在上述七个路径，没有清理共享 Hugging Face 缓存或其他实验目录。检查时没有发现额外的 Qwen 8B Hugging Face 缓存目录，也没有运行中的本实验编码进程。

原报告和结果文件保持原样，其内容描述测试完成时的状态；**清理后的本地权重和运行时状态以本记录为准**。

## 以后重新运行

查看已有报告、排名、标注及资源数据不需要下载模型。已有向量和独立实验索引也仍在。

若要重新执行 8B 推理，需要按保留的固定版本重新下载权重和 llama.cpp 运行时、重新编译适配器，并从源视频重新生成临时帧。原评估主入口包含权重文件审计，清理后直接重跑也会因权重缺失而失败；这是预期行为，不代表已保存结果损坏。历史结果目录应保留，新的运行使用独立目录。

本记录落实“继续使用 2B、暂不切换 8B”的决定，没有创建任何自动切换或重新下载任务。
