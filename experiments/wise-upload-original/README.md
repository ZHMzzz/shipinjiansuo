# 上传端 WISE 原版离线对照

仅实验目录写入。`benchmark.py prepare` 冻结来源；`benchmark.py suite` 暂停本项目服务，串行运行当前、原版、当前子集复测三个工作进程，在 finally 恢复服务。执行前需用户允许暂时停服。`evaluate.py` 汇总结果并验证生产保护文件。`replay.py suite` 在可丢弃的项目副本中回放两条视频的完整上传处理，也会暂停服务并在 finally 恢复。

原版来自本地 wise 仓库的上游 HEAD，不是包含本地补丁的工作文件。解码与编码原始源码导出到 reference/，记录 commit 与 SHA。相同本地模型权重、已转码视频、查询文本及 WISE 排序代码；查询不加额外英文前缀。试验不启用阈值、拆句、重排。

质量主表使用已冻结的 40 个视频和 68 条查询，按视频级标注评价（相关性取该视频所有已标注片段的最大值）；第 41 个未标注视频不强行计作负例。视频定位边界不同，不能将视频命中率当作精确片段定位准确率。

从仓库根目录先 `source scripts/env.sh`。设计和结果目录禁止覆盖，重跑需另建实验目录并重新冻结状态。原版含原生视频采样、Qwen 编码和特征索引格式；完整上传回放仍保留本项目的转码、OWLv2、人脸处理与项目复制阶段，不代表完整原版 WISE CLI 的所有默认部署选项。
