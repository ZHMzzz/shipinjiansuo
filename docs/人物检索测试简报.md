# 视频检索测试简报

测试日期：2026年10月29日。

## 一、人物检索

系统支持同一姓名维护多张人脸照片。本次以沈腾为目标人物，登记4张人脸照片，使用姓名检索当前视频库，人脸相似度门槛为0.45。测试集共13个目标人物视频，包含多人同框和密集人流场景，视频内容及场景由测试人员确认。

| 测试项目 | 结果 |
| --- | --- |
| 姓名检索 | 返回13个视频，与测试集完全一致 |
| 视频级 Precision | 100%（13/13） |
| 视频级召回率 | 100%（13/13） |
| 视频级漏检 | 0个 |
| 命中画面人工核验 | 13/13正确，命中时间处均出现目标人物 |
| 多人场景身份区分 | 本批返回画面经人工核验，未发现身份混淆 |
| 时间定位 | 支持跳转播放，13个返回结果的定位均经人工核验正确 |
| 单次接口响应时间 | 约0.84秒 |

本次测试验证了多照片登记、姓名检索和命中时间定位功能。视频级 Precision 与返回命中画面的人工核验正确率均为100%，在本批样本上达到课题提出的 Precision ≥90%目标。测试包含多人同框和密集人流场景，未发现返回画面的身份混淆。结论限于本批13个视频及其返回命中画面，不代表全视频逐帧评测结果。

## 二、以图搜视频

使用2张红色背包参考图，在当前视频库中检索；核验样本为2个红色背包目标视频和1个黑色背包干扰视频。

| 测试项目 | 结果 |
| --- | --- |
| 目标视频召回 | 两张图片均找全2个目标视频，各次视频级召回率为100%（2/2） |
| 排序与抗干扰 | 按模型相似度排序；黑包仍排在部分红包结果之前，颜色区分需改进 |
| 可视化与定位 | 返回视频缩略图及命中时间，支持跳转播放 |
| 接口响应时间 | 本机6次查询约0.8～2.6秒 |

本次验证了以图搜视频的基本功能及小样本目标视频召回。尚未系统评测角度偏移、亮度剧变和尺寸差异，不能据此确认课题要求的复杂变化下检索覆盖率≥85%；颜色抗干扰能力仍需完善。

## 三、自然语言场景与动作检索

场景与动作样本共27个：雨天、晴天街道各5个，跑步类6个（含跑酷1个），散步／走路5个，人物打架5个、猫打架1个。采用全库检索；跑步、散步及天气查询的评测库包含90个视频，打架及复合条件查询的评测库包含92个视频。

| 测试项目 | 结果 |
| --- | --- |
| 雨天街道 | 3种近义表达均将5个雨天样本排入前5，Precision@5 均为100%（5/5） |
| 晴天街道 | “晴天街道”前5条中4条来自晴天组、1条为雨景；晴天组含云层较多的样本，严格天气标注需统一 |
| 跑步 | “跑步”前5条均包含跑步动作，Precision@5 为100%（5/5）；跑酷样本搜“有人在跑酷”排第1 |
| 散步／走路 | “散步”前5条经画面核验均包含行走，按可见行走动作判定，Precision@5 为100%（5/5） |
| 人物打架 | “打架”前5条经画面核验均包含打架动作，Precision@5 为100%（5/5）；其中4条来自测试集、1条为库中其他视频，剩余1个测试样本排第7 |
| 猫打架 | “猫在打架”将目标视频排第1；人物打架查询仍返回猫视频，主体条件过滤不严格 |
| 表达稳定性 | 林间散步样本搜“散步”排第2，“有人散步”排第13，“两个人在林间散步”排第1，措辞对排序影响较大 |
| 复合条件 | 测试昼夜打架、商场打架、海边跑步、林间双人散步、雪地三人行走及晴雨天公交车等8条语句，首位结果均包含同时满足条件的画面（8/8）；前5条仍混入时间、人数、场所或主体不符的结果 |
| 时间定位 | 可跳转至相关场景，但动作边界不够精细；餐馆打架起点约提前3秒，商场打架在特定表达下定位至末段拉扯、劝阻画面，返回范围仍包含片尾 |
| 接口响应时间 | 本机19次跑步、散步及天气查询约0.06～1.05秒；5次打架相关查询约0.08～0.87秒 |

测试验证了场景、动作、部分近义表达及复合描述的检索能力；晴雨区分、表达稳定性、复合条件过滤和动作边界定位仍需改进。复合查询首位命中不代表前5条全部正确，部分查询在库中可能不足5个正确结果。小样本结果尚不能据此确认标准测试集 Top-5 准确率≥85%或10GB规模下平均响应时间＜3秒。
