# Qwen 片段统一存储到 WISE

用户确认移除额外的 action-index 快照，复用已有向量，将自然语言与人物场景查询、上传、补建、状态统计统一到 WISE 元数据和向量存储。保留 FP16、1048576 像素预算及现有抽帧窗口；这是存储与维护简化，不是改用原版 FP32 编码或声称精度、速度提升。更新 ADR 0001 中独立片段索引的实现选择，其他检索含义不变。

WISE 标准特征文件与搜索索引仍保留。项目中仅增加编码配置及媒体签名清单，不再复制一套片段向量和时间记录。人物融合的兼容视图在内存生成，不持久化。上传调用 WISE 帧特征提取时，暂时把 Qwen store 移出自动发现目录并在 finally 恢复，随后直接写入新旧 Qwen 向量；不能删除唯一向量来源再补建。

迁移在新发布副本完成，已有向量和 ID 保持一致，原子替换活动指针，旧发布版本保留用于回退。历史版本可能仍有旧格式，因此旧格式读取限于迁移和历史兼容；删除仍遵循 ADR 0006，同时清理历史旧格式和 WISE 向量，防止已删除视频重新出现。配置不符或索引损坏时不得静默退回过期的旧快照。
