# 仅保留当前索引和上一发布版本

用户确认发布成功后自动回收更早的完整索引副本，避免每次入库都永久增加一份全库索引。这更新 ADR 0002、0007 中无限期保留旧版本的策略；仍先复制、校验并原子发布，再保留当前版本与实际被替换的上一版本，不能按目录修改时间推断发布顺序。

发布关系和待回收版本写在 release 根目录的 publication.json，位于复制的 demo 目录之外。只回收活动发布记录明确列出的旧版本，不扫描删除未发布草稿或未知目录。上线时显式登记已核实的旧版保留关系；发布失败不清理，清理失败不撤销成功发布，后台及重启后重试。保留原有写入互斥，查询和图库元数据读取在发布切换前结束；本规则不修改视频原件、转码视频或运行环境。

删除视频仍遵循 ADR 0006：先清理历史副本中的该视频，完成可恢复的删除记录后再回收多余版本，保留下来的上一版也不能恢复已删除视频。构建期间会暂时同时存在两份保留版本和一份新版本；本次不改变向量格式、抽帧策略或特征与搜索索引的双份存储。
