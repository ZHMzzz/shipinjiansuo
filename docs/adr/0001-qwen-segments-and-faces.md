# 使用 Qwen 片段索引统一视觉语义检索，保留专用人脸索引

物体检索部分已由 [ADR 0002](0002-restore-wise-owlv2.md) 更新：按用户明确选择恢复 WISE2 OWLv2 链路。
用户在对照验证后决定移除正式链路的 SigLIP 与 OWLv2，复用已有 Qwen 片段向量，减少模型维护和上传计算；不再提供物体框。图片与文字联合编码采用已有片段索引的输入模板，避免改模板导致重建全库。

InsightFace 继续负责登记人物与身份门槛。人物的场景条件只在包含人脸命中时刻的同视频片段内排名，不能再称为同帧判断。截图由 Qwen 召回候选，再用画面相关性细化。现有 8 秒窗口、4 秒步长与 16 帧配置不变，不能据此承诺短暂小目标或精确动作边界。

迁移创建保留历史的独立发布版本，校验 Qwen 文件和人脸向量未变后原子替换活动指针；正式新视频只提取人脸帧特征和 Qwen 片段特征。历史研究编码器源码与模型缓存保留，但不在正式入口加载或入库。

## 用户图片回归后的补充

新闻局部截图暴露整帧精排的几何失配；挖掘机和太阳镜图暴露图片与片段表示的外观差异。维持 Qwen + 人脸路线，截图增加几何对齐，物体查询提供默认开启但可关闭的候选代表帧比较。代表帧仅按查询计算并在进程内缓存，不建立全库帧索引，不增加入库计算。以额外查询耗时换取已测外观查询改善；不等价于完整恢复 OWLv2 区域能力。见 [用户图片回归](../用户图片检索回归.md)。
