# 删除视频时清理全部索引副本

用户要求删除视频及对应检索索引。活动索引先在副本中清理、校验并原子发布，然后按来源路径与校验标识定向清理历史项目中的该视频、特征、缩略图和 Qwen 片段，避免旧特征在重建或回退时重新出现。这更新 ADR 0002 的“旧发布版本保留”：历史版本继续保留其他视频，但不能恢复已删除视频。

删除与入库使用同一个写入锁；发布前失败不改变当前视频库。发布后的历史文件清理通过持久记录恢复，在清理完成前不发布后续入库版本。请求携带与项目版本及媒体身份绑定的确认标识，避免 ID 复用导致旧页面误删新视频。清理应用托管的视频和上传原件，不触碰托管目录外的导入源文件，也不删除独立的人物登记库。
