# 物体图片恢复 WISE2 OWLv2 原生链路

用户在提供真实失败样本后明确选择“恢复 OWLv2 的 WISE2 官方链路”。这更新 ADR 0001 中统一物体检索到 Qwen 的决定；文字、图文、动作、截图召回及人脸部分保持原决策，截图几何对齐修复继续保留。

物体页面直接调用 WISE `/demo/search`，指定 OWLv2 编码器，使用原生图片查询、区域向量、FAISS 搜索、元数据与排名，不再调用 Qwen 候选帧精细匹配。保留当前本地 WISE 中既有的 MPS 适配与查询向量格式修复。API 仍提供原生物体框，MVP 页面按用户此前要求隐藏框。

入库恢复 OWLv2 + InsightFace 每秒两帧特征，随后构建新增 Qwen 片段。移除 SigLIP 的要求继续生效。恢复 OWLv2 会增加入库计算，因此仅 Qwen + 人脸阶段的时间节省估算不再适用。

已有 OWLv2 特征通过 WISE 的项目合并功能导入新发布副本，向量 ID 由 WISE 重映射以避开新增人脸 ID；缺失视频使用 WISE extract-features 生成。验证保留内容、区域元数据及索引对应关系后才切换活动指针。旧发布版本保留。
