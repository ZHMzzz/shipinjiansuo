# 统一以图搜视频入口

用户要求把截图溯源和物体图片合为一个入口。更新 ADR 0002 的页面入口安排，保留其 WISE2 原生物体算法、排序、索引和上传链路。

页面一次上传，先调用原生 `/demo/search` 指定 OWLv2，立即显示物体结果，再调用现有 `/mvp-api/trace`。截图画面对比达到 0.90 的候选优先显示，之后保留 OWLv2 原有顺序；同一视频只显示一次。两路分数不相加、不直接跨模型比较。卡片分别标注“画面匹配”和“物体相关”。0.90 是保守的本地启发式，尚未用独立数据集标定，不是来源真实性证明；截图召回仍受现有前五候选及前 60 秒细化范围限制。

一路失败时提示用户并保留另一路结果。完整查询多出截图召回与画面对比时间，但物体结果先显示。没有新增模型或入库工作，物体框仍隐藏，人脸及图文组合维持原功能。
