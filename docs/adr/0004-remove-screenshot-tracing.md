# 移除截图溯源，仅保留物体图片

用户明确要求去掉截图溯源功能。取代 ADR 0003 的统一图片入口及 ADR 0001/0002 中保留截图溯源的部分。

图片入口恢复“物体图片”，直接调用 WISE2 `/demo/search` 并指定 OWLv2，保持原生向量、区域检索和排序。删除 `/mvp-api/trace`、截图画面对比/局部对齐、两路结果合并代码及专属测试。不存在截图来源识别和精细时间定位的后台步骤。旧接口返回 404，旧页面刷新后使用物体入口。

不修改已有视频、索引或入库流程；Qwen 文字、图文组合、动作与人脸检索保留。物体框继续隐藏。历史验证文档记录的是当时结果，截图溯源不再是当前能力。

## 验证

`python -m pytest tests -q`：40 项通过。服务重启后 `/mvp-api/trace` 返回 404。两张用户物体图仍首位命中正确视频：挖掘机 0.96 秒、太阳镜 0.88 秒（本机单次）。浏览器确认物体查询只有一次指定 OWLv2 的 `/demo/search` POST，没有截图请求或控件。

额外从仓库根运行无目录限定的 pytest，包含上游 WISE 自带测试：`TestWithEmptyProject.test_get_info` 期望 `max_search_results=1000`，本项目既有 `wise_config.yaml` 配置为 100，断言失败；随后上游网络相关测试等待时手动中断（当时 48 passed、1 failed）。本次没有修改该配置或上游测试，项目自身 tests 目录已独立全部通过。
