## 验证覆盖

- 真实模型推理与 FAISS 查询；预期视频在各项查询的首位。结果 JSON 保留在 `logs/verification.json`。
- 截图实际抽取时刻 2.25 秒，细化定位 2.30 秒，本例偏差 0.05 秒。单用语义向量曾匹配到相似动作的 5.50 秒，因此新增画面比对，不隐藏这一差别。
- 独立背包照片并非视频截图；物体模型的前两位分别为两个背包视频，目标框目视核验通过。
- 人物登记实际提取 512 维特征并存入 SQLite；重启服务后可按姓名查询。人物首位相似度 0.950，页面以 0.45 门槛显示目标视频。
- 未登记姓名返回 404；背包照片登记为人脸返回 400；视频分段请求返回 206，浏览器已实际播放命中片段。
- Chrome 完成中文检索、截图示例、独立背包示例、姓名示例的按钮操作和结果检查。
- WISE 前端构建通过；新增 Python/JS/shell 语法检查通过；上游 query parser 测试 1 项通过。

## 观察到的局限

- 背包检索第三名是围裙区域的误匹配，分数 0.963，说明高相似度不是正确概率。本演示保留这些误匹配，没有按预期答案过滤。
- 人脸登记图来自同一视频的另一个时间帧，仅验证链路；不是跨摄像头、密集人群身份区分的独立测试。
- 截图精排最多 5 个候选，每段扫描前 60 秒，按约 10Hz 采样。当前支持截图画面比对，强裁剪、镜像与长视频需要扩展。
- 这些结果不是标准测试集评估，不能推出 85% / 90% 课题指标，也没有验证 10GB、并发或 7×24 稳定性。
- 原版 WISE 界面保留，中文 MVP 的姓名登记与截图精排属于本项目新增功能。
