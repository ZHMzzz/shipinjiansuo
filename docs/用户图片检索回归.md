# 用户图片检索回归

> 后续决定：用户已明确选择恢复 WISE2 OWLv2 物体链路，Qwen 物体精细匹配已移除。当前行为以 [恢复 WISE2 物体检索](恢复WISE2物体检索.md) 为准；本文保留前一阶段记录。
2026-10-27。用户提供一张局部新闻截图、一张白底挖掘机商品图、一张透明底太阳镜图，反馈正确目标找不到或排名过后。以原图重放实际接口，而非仅检查演示图片。

## 原因与对照

| 图片 | 修复前 | 原因与处理 |
| --- | --- | --- |
| 新闻截图 | Qwen 已召回来源视频 22 为首位；灰度精排把它降至第三，相关性约 0.334 | 截图只包含视频局部，整帧拉伸比较破坏对应关系。增加 SIFT 匹配、RANSAC 单应性验证、对齐后相关性比较 |
| 挖掘机 | Qwen 片段首位是吊装作业，挖掘机来源 21 排第二 | 片段语义不等于静态物体外观。查询时对前 20 个候选片段的中间帧用同一 Qwen 编码器重新比较 |
| 太阳镜 | Qwen 将多个不相关场景排前，已知太阳镜视频 14 / 13 为第 7 / 12 | 同样存在片段与图片外观不一致；文件还包含透明通道，直接转 RGB 会暴露不可见的绿色背景。修正 alpha 合成，并追加候选帧比较 |

旧模型对照使用保留的 32 视频发布版本，未切换在线库。旧 SigLIP 首位是来源 22，OWLv2 挖掘机首位是 21、太阳镜首位是 13。现有库此时已增长为 38 视频，不能把不同候选库的排名当作完整的公平模型评测。

单独把透明背景合成白色后，太阳镜视频 14 / 13 仍排第 10 / 18，说明背景处理不是主要原因，不能声称只修 alpha 就解决了检索退化。候选帧比较后视频 14 排第一。

## 实现边界

- 保持 Qwen + InsightFace 正式路线，未恢复 SigLIP/OWLv2；用户关于恢复 OWLv2 或接受较慢 Qwen 查询的偏好询问尚未收到回复，本次先沿用此前移除旧模型的要求，提供可切换的 Qwen 精细匹配。
- 物体入口默认开启“精细画面匹配”，可关闭恢复快速片段检索。API `POST /mvp-api/search` 新增 `refine`，默认 false，仅允许纯图片查询。
- 精细匹配只比较召回前 20 个视频各自最强片段的一个中间帧；保留片段起止时间和原排名，不生成物体框，不代表同一实物识别，也不能救回候选之外的目标。短暂物体可能不在代表帧中。
- 代表帧向量仅在进程中缓存，最多 256 条，缓存键包含不可变项目版本；视频入库流程、持久 Qwen 索引和人脸索引不变。
- 截图保留原完整画面约 10Hz 扫描；低相关性候选补充约 1Hz 几何匹配，再在最佳时刻附近细化。至少 8 个几何内点、内点比例与覆盖范围、投影有效性都通过后才接受对齐结果。每候选前 60 秒的扫描限制保持不变。
- 透明图片先合成白底，EXIF 方向归正；不更改原始用户文件。

## 真实验证

运行 `scripts/verify_image_regressions.py`，输入用户三张原图：

| 图片 | 修复后首位 | 时间 / 分数 | 首次本次 HTTP 耗时 |
| --- | --- | --- | ---: |
| 新闻截图 | 抖音20261026-905866.mp4 | 30.0 秒；对齐相关性 0.984 | 14.93 秒，含 Qwen 冷加载 |
| 挖掘机 | 摔倒01_白天工地.mp4 | 0–8 秒；画面相似度 0.395 | 12.42 秒 |
| 太阳镜 | whistling-OdLV8MmYkKI_000001_000011.mp4 | 4–10 秒；画面相似度 0.267 | 10.28 秒 |

截图独立精排本次约 6.53 秒。浏览器再次查询太阳镜命中全部 20 条帧缓存，用时约 0.02 秒；该数值不能作为新图片或冷缓存延迟承诺。

自动化测试 40 项通过；新增局部裁剪几何对齐、无特征图片拒绝几何匹配、透明 RGB 隐藏数据、帧排名及版本缓存隔离回归。原中文/截图/图片/人脸、图文与人物场景、动作检索脚本通过。独立背包和安全帽补充检查的首位仍是已知同类目标。

浏览器确认精细匹配默认开启、关闭后走快速查询、结果显示原排名且无物体框，新闻截图从 30 秒播放；无应用脚本错误，仅既有 favicon 404。发布前后活动项目指针、Qwen 向量、人脸资产及缩略图指纹相同。

## 复现

```sh
source scripts/env.sh
python -m pytest tests -q
python scripts/verify_image_regressions.py /path/to/screenshot.png /path/to/excavator.jpg /path/to/sunglasses.jpeg
```

用户图片不复制进 Git。实际响应、图片 SHA-256、旧索引对照和只读诊断脚本保存于本机忽略目录 `logs/user-image-regression/`；其中 `frame_probe.py`、`crop_probe.py` 为本次诊断用途，不参与线上服务。
