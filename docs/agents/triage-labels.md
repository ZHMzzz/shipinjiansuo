# Triage Labels

| 标准角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 需求明确，可交给代理自主执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提到某个 triage 角色时，使用对应的本项目标签。
本地任务通过文件顶部的 `Status:` 行记录标签。
以后可以修改“本项目标签”列以适配新的命名。
