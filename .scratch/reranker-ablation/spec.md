# 重排安全帽对照实验

用户授权执行五类小样本对照：分辨率、局部区域、抽帧、提示词、同场景戴帽/未戴帽配对。固定 Qwen3-VL-Reranker-2B 与 FP16/MPS，不修改 Demo 默认配置，不把标签、文件名喂给模型。

先复现固定短片基线，再一次改变一个因素。抽帧分成固定像素预算与固定实际分辨率两组，避免把帧数和分辨率效应混为一谈；时间元数据修正单独比较。手工区域仅作为已知目标位置的诊断上限，不声称已实现自动区域检测。配对素材需视觉核对并记录来源、裁剪框和局限。

交付可复现脚本、原始得分/排名、实际输入形状与 token 数、计时/内存、图像核对材料和中文结论。阶段写入结果，实验结束恢复服务并确认索引不变。
