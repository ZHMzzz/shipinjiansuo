# WISE 原生自然语言检索验证

2026-10-27。修改前备份提交 72d83d0 已推送到 origin/codex/video-delete。

## 行为

纯文字查询与文字加文件名查询使用 WISE EmbeddingService、LocalSearchService 和 search_output_to_response。保留原始中文输入（配置 query_prefix 为空）、既有 Qwen FP16 模型和片段向量；未加入自动拆句、阈值或重排。当前服务配置最多取 100 个片段，再使用 WISE 合并的片段按最高分展示视频卡片；同一视频一张卡片，每页 50 条。播放从最高分命中的 thumbnail_ts 开始，结束时间来自 WISE 合并片段。

这是对 ADR 0005 中“高度重叠候选过滤”的后续调整：纯文字入口不再用自定义 select_hits，而使用 WISE 原生片段合并。人名与场景的融合链路及其门槛保持原行为。
