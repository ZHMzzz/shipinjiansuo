# 动作片段可选重排

接入官方 Qwen3-VL-Reranker-2B，用户在动作检索中选择开启/关闭；开启时展示同一候选集重排前后的结果、原排名和独立分数，可从对应时间播放。普通查询及上传索引保持兼容。

默认重排前 10 个候选，允许选择 5/10/20；查询时逐片段推理，保留原始召回结果，不能把未被重排的分数混排。不向模型传入文件名或人工标签。按需加载及释放模型，采样服务 RSS、MPS、系统可用内存和 swap，独立列出耗时；不同内存口径不相加。

重点用中文未戴/戴安全帽、翻越围栏、摔倒对比，固定候选集与参数保存原始结果。报告实际成功或失败，区分小样本现象与验收指标；区分冷启动和热查询。

步骤：核对并下载固定版本模型 → 实现推理/API/开关 → 边界与回归验证 → 本机实测及浏览器对比/播放 → 文档与结果交付。
