# 8B 8-bit 与现有 2B 的独立检索对照

用户授权：测试 Qwen3-VL-Embedding-8B 的 8-bit 量化版，比较检索效果、速度和内存；不替换现有模型和索引。

## 边界与执行计划

1. 保存活动项目指针、正式配置与索引文件 SHA-256；全程只读正式数据。
2. 下载固定版本的量化权重与独立运行时，放入实验目录；不升级正式 Python 环境。
3. 优先复用已有人工标签动作样本，固定候选集、查询、16 帧及像素预算；标签和文件名不传给模型。
4. 先验证多帧视频输入、末 token 池化及归一化，再顺序运行两个模型，分别记录加载、片段编码、查询编码、向量检索耗时以及 RSS／Metal／系统内存。
5. 实验报告明确运行时、预处理或模板差异；不将差异全部归因于模型规模或量化。
6. 复核正式配置、活动指针和索引哈希，交付可复现脚本、原始结果与结论。

## 验收

- 两个模型均实际完成同一候选集检索，给出逐查询排名及汇总指标。
- 加载与首次执行单独列出，热查询不使用结果缓存；内存不重复叠加 RSS 与 Metal。
- 小规模既有样本仅作探索性对照，不作为泛化准确率证明。
- 正式模型、配置、索引和服务不被实验替换。
