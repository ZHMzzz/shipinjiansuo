# 隔离比较 Qwen 与帧特征三种调度模式
Status: ready-for-agent
Type: task
Resolution: completed

用户要求分开测试串行、完整并行、仅 CPU 解码/预处理并行，比较完整入库耗时、内存及检索效果；不改变正式环境。

同一 35.44 秒视频与完整库副本，统一预热后交错重复。完整并行提前编码 Qwen；CPU 模式使用最多两个片段的预处理队列，Qwen GPU 推理在帧提取结束后执行。计算输出先暂存，媒体 ID 确定后串行写入、统一校验发布。观测父进程及后代 RSS/USS、各 Torch 进程 MPS 分配器，以及系统可用内存和 swap，注明不可相加为物理总内存。固定查询、向量及元数据回归，保存正式状态指纹。
