# 索引优化隔离对照实验

用户授权测试 OWLv2 快速处理器、MPS 半精度和 InsightFace CoreML，对比耗时与检索效果。仅实验，不切换生产配置。

固定同一批视频、每秒两帧、OWLv2 960 输入与 0.02 区域阈值、人脸 buffalo_l/640/0.5 检测阈值、0.45 人脸门槛。Qwen 2B FP16、8 秒窗口/4 秒步长/16 帧保持不变。

先跑相同真实 WISE extract-features/create-index 路径的基线，单因素比较 slow/fast × FP32/MPS autocast FP16，再比较 CPU/CoreML。所有重推理串行。候选失败需记录，不静默回退并报告为加速成功。首次模型加载/编译、热推理与完整子进程耗时分列。

检索使用冻结参考图，保留原生 WISE query hook；比较固定子库与替换样本向量后的完整生产背景。既有裁剪图为同源测试，独立类别参考图单列，不把排名稳定性声称为全面准确率。人脸比较检测、向量、已有登记向量检索及门槛一致性。

通过筛选的配置复测，并对实际新视频入库阶段做隔离回放，区分 WISE 阶段与包含转码/Qwen/校验的整体耗时，不纳入网络上传或真实生产发布。保存输入/配置/源码哈希、原始 JSON、日志和报告。核验活动指针、正式索引、正式源码和登记库未被实验改变。
