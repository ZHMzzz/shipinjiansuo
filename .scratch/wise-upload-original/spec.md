# 上传端对齐 WISE 原版的离线比较

用户要求比较自然语言检索效果、视频索引建立耗时、查询耗时，不接入正式页面。用户已明确允许实验期间暂时停止本地检索服务，结束后自动恢复。

固定当前 41 视频来源、正式向量与配置，以及已有 40 视频 / 68 查询标注。主质量指标只在已标注的 40 视频范围计算；第 41 个视频用于全库性能及诊断，不擅自标为负例。无答案查询单列，不能用强制 Top-K 声称已过滤误报。

比较 A：现有 OpenCV 固定 16 帧 / FP16 / 1048576 总像素预算；B：原版 WISE 解码器与原版 Qwen 编码器 / Mac 默认 FP32 / 7864320 总像素预算，查询仍用 A；C：同 B 的视频索引，查询也用原版 FP32。检索均用 WISE 原生候选截取与片段合并，视频展示去重。

导出本地 WISE 上游 HEAD 原始源码到实验目录执行，记录来源与 SHA；不修改 wise/、scripts/、ui/、wise_config.yaml 或活动索引。串行运行，记录模型加载、视频解码与编码、索引写入及查询阶段，监测内存。先完成全库比较，再按实际观测决定是否需要额外阶段回放。
