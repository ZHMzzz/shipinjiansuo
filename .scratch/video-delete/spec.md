# 视频删除与索引清理

采用用户选定的删除入口 A（原型 `codex/prototype-video-delete` / `3dede80`）。卡片底部使用同一 flex 行显示元信息和删除按钮，取消原型绝对定位。

点击确认后删除整段视频，包括该视频的所有语义命中片段。基于当前发布副本清理 SQLite、物体和人脸 FAISS 索引及特征分片、Qwen 片段和缩略图，校验后切换。删除与上传索引构建互斥。请求绑定媒体身份，防止 ID 复用后误删新视频。

删除生效后定向清理含该视频的历史项目副本及托管视频文件、对应上传任务，以免重建或旧快照带回已删数据。只处理匹配来源路径和校验标识的视频；其他视频向量与登记人物不变。清理日志随发布版本持久保存，异常中断后继续清理。测试使用专门创建的临时视频，不删除用户已有素材。
